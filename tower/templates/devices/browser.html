Install Chrome extension

Download latest All versions
  1. Download the zip and unzip it. The folder must contain manifest.json.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode.
  4. Click Load unpacked and select the unzipped folder.
  5. Open the extension popup, turn Agent ON, and copy the pairing code.
  6. Paste that code under Add browser below.
